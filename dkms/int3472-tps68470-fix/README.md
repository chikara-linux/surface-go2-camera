# int3472-tps68470-fix — 休止状態から戻るとカメラが動かない件

TPS68470（カメラ用の電源・クロック制御チップ）の上流ドライバ
`intel_skl_int3472_tps68470` に、休止状態（hibernate）用の保存と復元を足したもの。
カーネル 7.0（Ubuntu 7.0.0-38）の `drivers/platform/x86/intel/int3472/` が元。
Ubuntu の差分はこれらのファイルに触れていない（`discrete.c` のみ）。

## 症状

休止状態から戻ると、赤外線カメラ（ov7251）・背面カメラ（ov8865）・フォーカス用
モーター（dw9719）が I2C で `-121` になり、顔認証が「not possible to open camera」で
失敗する。再起動すれば直る。スリープ（s2idle）では起きない。

## 原因（2026-10-09 に実機で確定）

休止状態では電源が切れ、TPS68470 は初期値で目覚める。復帰後に読んだ値:

| 区分 | レジスタ | 復帰後 | 本来 |
|---|---|---|---|
| PLL の分周 | 0x06〜0x0c | すべて 0x00 | XTALDIV 0xAA、PLLDIV 0x20 など |
| 背面 avdd・VCM・赤外線 vdda | ANA/VCM/AUX1 | 0x00 = 0.875 V | 109 = 2.815 V |
| 背面 dvdd | CORE | 0x00 = 0.900 V | 12 = 1.200 V |
| 赤外線 vdddo | AUX2 | 0x00 = 0.875 V | 52 = 1.8006 V |

ところが上流のドライバは、PLL の設定を clk-tps68470 の `set_rate()`（同じ周波数なら
二度と呼ばれない）で、電圧をレギュレータ登録時に**一度だけ**書き、休止状態の
復元処理を持たない。復元されたカーネルは設定済みだと思い込んでいるので、
センサーには電源もクロックも来ない。

## 直し方

`tps68470-hibernate-restore.patch`。スナップショット作成時（`.freeze`）に設定レジスタを
読んで保存し、復元時（`.restore`）に書き戻す。順序はチップの依存関係に合わせる:
PLL の設定 → PLL の有効化（4〜5 ms 待つ。clk-tps68470 の `prepare()` と同じ）→
電圧 → 電源の入切 → GPIO の出力値 → GPIO の向き。

保存するのは「その瞬間にカーネルが思っている状態」そのものなので、使用中の
レールも止まっていたレールも、カーネルの認識とハードウェアが一致した状態に戻る。

## 机上で確かめたこと

- **順序**: 背面カメラとモーターは TPS68470 のレギュレータへの device link を持ち、
  レギュレータの親はこのデバイス。PM コアは親と supplier を待つので、ここの
  `.restore` は彼らの復元より先に走る（モーターが復元で -121 を出していた所）
- **起動用カーネル**: このモジュールは initramfs に入っていないので、休止状態から
  戻るときの起動用カーネルはチップに触れない。入れたとしても、保存値は
  復元されたカーネル側のもので上書きされるので害はない
- **休止状態の中断**（`.thaw`）: 電源は切れていないので何もしない
- **スリープ（s2idle）**: `.suspend`/`.resume` は定義していないので挙動は変わらない
- **保存の失敗**: 休止状態は止めず、復元を飛ばすだけ（警告を出す）
- **赤外線照明**（自作の tps68470-irled）: 点灯のたびに全レジスタを書き直す作りなので
  対象外でよい
- **前面カメラ**（ov5693）: TPS68470 ではなく SoC の GPIO から給電（int3472-discrete）。
  影響しない見込み（休止状態の試験で確認する）
- 保存状態は devres に置く。クライアントデータは regmap で、子デバイス（clk・
  レギュレータ・GPIO）が親から引くので変えられない

## 検証（2026-10-09、電源につないだまま `systemctl hibernate`）

| 確認 | 結果 |
|---|---|
| 復元処理 | `Restored PMIC configuration after hibernation` |
| フォーカス用モーターの `-121` | 出なくなった |
| TPS68470 の 41 レジスタ | 休止状態の前と**すべて一致** |
| 顔認証（ロック画面） | 復帰直後に 2 回成功 |
| 前面カメラ | 正常 |

## 導入

```bash
sudo cp -r int3472-tps68470-fix-1.0 /usr/src/
for k in $(ls /boot/vmlinuz-* | sed 's|/boot/vmlinuz-||'); do sudo dkms install -m int3472-tps68470-fix -v 1.0 -k $k; done
# 再起動
```

## 注意

- カーネル更新のたびに DKMS がこの 7.0 のソースで作り直す。上流がこのファイルを
  変えても置き換わらない（他のカメラ用 DKMS と同じ事情）。**上流が休止状態の復元を
  入れたら、この DKMS は外す**
- 上流に報告する価値がある（platform-driver-x86 / Hans de Goede、Daniel Scally）
